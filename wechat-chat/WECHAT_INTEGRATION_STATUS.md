# WeChat連携状況

確認日: 2026-11-09。Mockの双方向チャットは動作済みです。**実WeChatの自動同期・送信は未完成です。画面OCRによる手動取り込みを補助機能として実装しました。OCRを恒久的な同期方式とは位置づけていません。**

## 実装済み

| 機能 | Mock | Windows UIA | Windows OCR（補助） |
|---|---|---|---|
| 接続状態 | 接続・切断を再現 | プロセス、バージョン、最小化、ログイン画面、公開UI部品数を診断 | 手動モードを明示。ログイン・オンラインとは断定しない |
| 会話・履歴 | 個人3・グループ2、サンプル履歴 | 現クライアントでは未対応 | 表示中の文字を読み、本人が会話・本文・方向・送信者を確認して保存 |
| 新着の自動監視 | WebSocketへ反映 | 未対応 | 未対応。手動で取り込んだ結果はWebSocketで反映 |
| 送信 | 永続キュー、宛先照合、成功／失敗／確認不能 | 常に停止 | 常に停止。取り込みは送信キューを使わない |
| 正確な日時・外部ID | 取得・重複判定 | 未取得 | 未取得。日時不明、ローカル会話ID、OCR由来と明示 |

`WeChatAdapter` 契約は共通です。UIAは版別Reader未実装時に明示的なエラーを返します。OCRは自動Readerを装わず、`can_read=false` / `can_send=false` を維持します。明示操作の `POST /api/wechat/ocr/preview` と確認後の `POST /api/wechat/ocr/import` で手動取り込みます。診断・OCR・Mockは独立しています。

共通基盤にはSQLite、マイグレーション、重複判定、送信キュー、WebSocket、認証、再接続、優先度・定型返信案・タスクを実装しています。OpenAI向けの翻訳・返信案・要約・タスク抽出APIと確認画面も実装済みです。稼働環境では外部AIは無効で、実モデルの疎通・品質は未検証です。

## リスク・制限事項

1. 個人WeChatの通常チャットを自由に同期する公式APIは利用できません。非公式UI操作には利用規約への抵触・アカウント制限リスクがあります。[Tencent Weixin利用契約](https://oper.my-qcloud.com/cgi-bin/readtemplate?cc=CN&lang=en_US&s=default&t=weixin_agreement)
2. DLL注入、認証回避、プロセスメモリ読み出し、暗号化DB復号、プロトコル偽装は行いません。プロセス照会は QUERY_LIMITED_INFORMATION のみです。
3. OCRは画面に見える文字を読む補助です。会話・送信者・方向を自動確定せず、本人確認後に保存します。実送信は実装していません。
4. 同じ認識文と出現順による重複判定には、再投稿の誤抑制や認識差による重複があります。同名会話を自動結合しません。アカウントを切り替える場合は別DBを使います。
5. 日時は推定しません。timestamp=NULL、timestamp_quality=unavailable、identity_quality=ocr_reviewed とし、取得時刻と発言時刻を区別します。自分の発言も配信結果未取得です。
6. 保存DBは平文です。OSディスク暗号化と本人専用権限を前提にします。画像は保存せず、確認済み本文と会話情報のみDBに残します。
7. Windows OCRはMicrosoft資料ではパッケージIDを持つデスクトップアプリ向けです。今回の通常Python環境での動作を、全環境の対応とは扱いません。[Microsoft資料](https://learn.microsoft.com/en-us/uwp/api/windows.media.ocr?view=winrt-26100)
8. UIA診断は別プロセス8秒上限、OCRは別プロセス10秒上限。エラー時に秘密情報・本文を返さず、クラウドOCRへ自動転送しません。

## 次に進める実接続

OCRを主方式に固定せず、非侵襲なUIAで本文・送信者・会話を識別できるクライアント／Adapterの組合せを検証します。本人による4.1.8.107へのダウングレード後も本PCのUIAは取得不可でした。追加の版変更や有料版購入を解決策と断定しません。メモリ改変などで画面公開を強制せず、通常の設定・起動条件で読み取り可能になる根拠を先に確認します。

Readerで実証できた項目だけを自動化し、安定した宛先照合ができてからSenderへ進みます。送信試験は本人が指定した相手・本文の明示許可後に限定します。「WeChat双方向同期完成」とは報告しません。

運用はWindows常駐＋PWA。既存のFunnel経路・アプリ認証を維持します。Synologyへの移行や追加サーバーは不要です。使い方は [画面OCR](docs/SCREEN_OCR.md)、検証記録は [テスト結果](TEST_RESULTS.md) を参照してください。
