# 将来のAI連携

現在、AIへの転送・APIキー保存・AI自動返信はありません。Windows上のバックエンドにAI Providerを追加すれば、携帯・Windows・Macの同じ画面から呼び出せます。携帯でAIモデルを動かす必要はありません。

## 追加する境界

```text
携帯 / PC の画面
  ├─ 会話を表示・送信 → 既存REST / WebSocket → Send Queue → WeChatAdapter
  └─ 選択範囲の翻訳・返信案 → 将来のAI API → AIProvider（ローカル / 外部API）
                                                ↓
                                      下書きとして本人に提示
                                                ↓ 本人が送信ボタンを押す
                                           既存Send Queue
```

AI ProviderはWeChat Adapterと別のモジュールとして実装します。必要な入力は本人が選択したメッセージと目的だけに限定し、会話履歴を自動収集・転送しません。APIキーはWindows側だけに置き、ブラウザへ渡しません。

ローカルモデルならPCの計算資源を使い、外部AI APIなら契約・料金・データ送信範囲を本人が確認してから有効にします。採用サービスは未定です。AIが出した返信案をそのまま自動送信せず、既存の宛先照合・キュー・送信結果管理を通します。

想定する追加順は、選択メッセージの日中翻訳、選択会話の要約、本人確認付きの返信案です。画像・音声・ファイルは `message_type` とメディア保存モジュールを拡張して扱います。これらは将来の拡張方針であり、実装済み機能ではありません。
