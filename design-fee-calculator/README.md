# THE TRIANGLE.JP Design Fee Calculator

日本語／簡体字中国語で使用できる、設計費見積用の静的Webアプリです。
React + TypeScript + Vite + Tailwind CSS。サーバー、ログイン、環境変数、データベースは不要です。

## 使い方

1. プロジェクト名、設計面積、プロジェクト種別、追加設計費を入力します。入力の変更と同時に計算します。
2. 通常表示は改定モデルのみです。「計算の内訳」で段階ごとの追加面積、単価、係数、最低料金適用を確認できます。
3. 「現行料金表との比較」を開くと旧料金と差額を確認できます。
4. 面積別シミュレーションは入力面積から500㎡ずつ減算し、選択中の係数を適用します。追加設計費は含めません。
5. 計算結果・中国語見積文・比較表・Excel用TSVをそれぞれコピーできます。Excelはセルを選び貼り付けると3列に分かれます。
6. 右上の日本語／简体中文で表示を切り替えます。入力値は維持されます。

プロジェクト名は空欄で開始します。新規見積には中国法人（上海多三角）の印影を標準で設定し、削除・再設定できます。発行会社を変更すると標準印影を外します。保存済み下書きの印影は自動で置き換えません。標準印影のデータは `src/assets/china-seal.json`、発行会社の既定値は `src/quotation.ts` で管理します。

入力内容はこのページのメモリー内だけに保持し、外部送信しません。再読み込みで初期値に戻ります。

## 計算と料金設定

料金の一元管理ファイル： **`src/pricing.ts`**

| 設定 | 用途 |
| --- | --- |
| `minimumFee` | 改定方式の最低料金（240,000 RMB） |
| `includedArea` | 最低料金に含まれる面積（150㎡） |
| `revisedTiers` | 追加面積の上限 `upTo` と限界単価 `rate` |
| `currentBands` | 現行26区分。比較用の原本値を保持 |
| `projectTypes` | 4種の係数と日本語・中国語の名称 |
| `simulationStep` | シミュレーションの差分（500㎡） |

区分は上限値を含みます。`revisedTiers` は面積上限の昇順で並べ、最後の `upTo` は `null`（上限なし）にします。単価は正数です。最低料金から順に各区分の追加面積を積算するため、区分数・面積・単価を変更しても計算ロジックは変更不要です。設定不備は起動時に検出します。改定設定を変更しても、現行表は基準として保持してください。

変更後は `npm test` と `npm run build` を実行します。テストは2026年の承認済み仕様を独立した期待値として保持しているため、正式な料金改定時はテスト期待値も根拠を確認して更新します。

計算関数は **`src/calculator.ts`** 内で分離しています。

- `calculateRevisedFee`：最低料金＋段階加算 → 係数 → 最低240,000元の保証 → 1RMBに四捨五入 → 追加設計費。
- `calculateCurrentFee`：150㎡以下は240,000元固定。150㎡超は区分単価×面積全体×係数を1RMBに四捨五入。150㎡超には最低料金保証を再適用しません。13,700㎡超は `null` を返し、外挿しません。
- 平均単価は基本設計費÷面積。追加費は含めず、表示時のみ小数1桁に丸めます。平均単価から総額を逆算しません。
- Decimal.jsによる十進数演算を使用し、金額を丸めるのは係数・最低料金適用後です。
- 追加設計費は非負の整数RMB。未入力は0です。面積は正の小数にも対応し、全角数字・正しい桁区切りも受け付けます。
- 非数、空欄の面積、0以下、負の追加費、計算精度を保証できない極端な数値はエラー表示し、コピーを無効にします。
- 大きい面積は50行ずつページ表示します。コピーは全ページを含み、一括コピーの上限は20,000行です。超過時は明示し、切り捨てたデータをコピーしません。

旧方式の150㎡以下の扱いは、今回の実装指示「150㎡以下：240,000元」を優先した固定額です。改定方式ではこの面積でも係数を掛けてから最低料金を保証するため、飲食・個人住宅は256,800元になります。差異は旧方式の説明に明示しています。

## 配置

`npm run build` で **`dist/`** にHTML・CSS・JavaScriptを出力します。Viteの相対ベースURL `./` を使用し、ルートでもサブフォルダーでも配信できます。

### Vercel

- プロジェクトのRoot Directoryを `design-fee-calculator` に設定。
- Framework Preset：Vite。
- Build Command：`npm run build`、Output Directory：`dist`。
- このフォルダーの `vercel.json` に同じ設定を同梱しています。
- 環境変数は不要です。

### Synology NAS

- ビルドした `dist/` の**内容**を、Web Stationで静的ファイルを配信するフォルダーへ配置します。
- 例：`web/design-fee/index.html` と `web/design-fee/assets/`。
- 設定済みのWeb StationのURL末尾 `/design-fee/` で開きます。NASの配信設定や公開範囲に合わせて使用してください。
- Node.jsをNAS上で動かす必要はありません。`index.html` をファイルとして直接開くのではなく、HTTP/HTTPSで配信します。
- HTTPSでClipboard APIを利用します。HTTPや権限拒否時は従来のコピー処理、それも使えない場合は選択可能なテキストダイアログを表示します。

### Invoice OSと同じNASへのデプロイ

本番用リポジトリは `C:\Users\kure\Desktop\triangle-invoice-os` です。入口URLは `https://trianglejp14f.synology.me/design-fee-calculator`。

ルートで `npm run build:design-fees` を実行すると、計算機のビルドが `public/design-fee-calculator/` に配置されます。ソースと配信ファイルを同時にコミットし、明示的なデプロイ依頼に基づいて `main` へpushすると、既存の `Deploy Synology` がNASを更新します。詳細は親フォルダーの `docs/design-fee-deployment.md` を参照してください。

## スケジュール表（2026.10.13.1）

トップの「スケジュール表を作成」、または見積書編集の「07 スケジュール表」から編集します。
工程名・開始日・終了日・担当・備考を入力すると、工程別の横棒を表示します。工程は最大40件で追加・削除・並べ替えが可能です。
開始日・終了日は初期状態では空欄です。日数は両端を含む暦日（土日祝日を含む）、並行工程も設定できます。
有効日付は1900〜2199年、全体期間は3,660日以内です。

「スケジュールPDFを作成」でA4横向きの単独PDFを生成し、表示される「スケジュールPDFを保存」でダウンロードします。
案件名・発行会社・発行日も必要です。書類の見出し言語は「01 案件・書類情報」で切り替えます。
「見積書PDFの末尾にスケジュール表を添付」を選ぶと、見積書PDF作成時に図面の後ろへ追加します。
「Excel用にコピー」は工程の一覧をタブ区切りでコピーします。

スケジュールは見積書と同じ下書きJSON・ブラウザー自動保存に含まれます。既存の下書きはそのまま読み込め、スケジュール未添付で初期化します。
スケジュールと見積書の業務内容・業務期間は独立して編集します。日付や工程を変えても料金は変わりません。
計算・日付検証は `src/schedule.ts`、画面は `src/ScheduleEditor.tsx`、PDFは `src/schedulePdf.ts` に集約しています。


### ガントチャートの直接操作（2026.10.13.2）

「スケジュール表を作成」で、チャートを広く表示する専用編集画面を開きます。「見積書を編集」で同じ下書きの見積書編集へ戻れます。
- 横棒をドラッグ：期間（日数）を保ったまま前後へ移動します。
- 左右の取っ手をドラッグ：開始日または終了日を1日単位で変更します。
- 「元に戻す」：直前のチャート操作を取り消します（最大20操作。入力欄や下書き読込で別の変更をした場合は履歴を区切ります）。
- 日付未設定の行をクリック・タップ：選んだ位置に7日間の工程を配置します。自動確定された契約期間ではなく、編集用の初期期間です。
- 工程名をクリック：「工程の詳細」が開き、名前・日付・担当・備考を直接編集できます。
- 表示倍率：全体・週単位・日単位を選択し、必要に応じ横スクロールします。
- キーボード：横棒または取っ手にフォーカスし、左右矢印で1日、Shift併用で7日調整します。Escでドラッグを取り消します。

ドラッグ中は仮表示のみで、離した時点で下書きに反映します。開始・終了日の逆転、対応年の範囲外、全体3,660日を超える移動を制限します。工程間の自動連動や休日除外は行いません。
操作UIは `src/ScheduleGantt.tsx`、日付移動の規則は `src/schedule.ts` の `rescheduleTask` にあります。


### ガント内編集・営業日・単独PDF（2026.10.14.1）

- ガント左欄で工程名・担当・備考を直接入力。↑ ↓で並べ替え、上部の「工程を追加」で追加できます。
- 暦日／営業日を選択できます。営業日は土日・選択国の祝日を除外し、中国は公式の振替出勤日を含めるか選択できます。
- 入力日付は切替時に変更しません。横軸・ドラッグは暦日単位で、移動後の日数は再計算します。休業日は薄い背景で表示します。
- 祝日データは `src/holidayCalendars.ts` に一元化。日本2026・2027年、中国2026年を公式資料で確認（2026-10-14）。中国2027年等の未登録年は営業日数を推測せず、警告を表示してPDF・Excel出力を無効化します。新年を追加する際は公式資料で holidays / workingWeekends / years / source / checked を更新してください。
- ガント上部の「単独PDFをエクスポート」で、見積書を作らずにA4横向きのスケジュールだけを保存できます。プロジェクト名・発行会社・発行日・工程名と日付が必要です。ブラウザーが自動ダウンロードを止めた場合は生成後の「スケジュールPDFを保存」を使用してください。
- 単独PDF・見積書に添付するPDF・Excelの全てに選択した日数方式を反映します。以前の下書きは暦日設定として読み込みます。


### 工程の上下ドラッグ・備考欄（2026.10.14.2）

- 左端の取っ手を上下にドラッグして工程を並べ替え。挿入位置の線を確認して離すと確定します。一覧の上下端で自動スクロール、Escで取消、元に戻すにも対応。キーボードでは取っ手にフォーカスして↑ ↓で移動できます。
- ガント内は工程名と日付のみ。担当欄は画面・PDF・Excelから除外しました。
- 「エクスポート時の備考欄」で備考を編集できます。PDFとExcelではガントの下の備考欄にまとめます。既存の工程別備考は工程名・現在の工程順とともに掲載します。
