Noto Sans SC, weight 400 static TrueType instance.
Source: https://github.com/google/fonts/blob/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf
License: SIL Open Font License 1.1, included in LICENSE.txt.
Prepared with fonttools 4.65.0:
python -m fontTools.varLib.instancer NotoSansSC-variable.ttf wght=400 --output=NotoSansSC-Regular.ttf
The full character set is retained for editable Chinese and Japanese quotations.
PDF generation subsets the font to the characters in each document.
