# 出金の傾向・注意

`/banking/insights?company=JAPAN`。口座・カード明細と口座予測からアクセス。
ADMIN / ACCOUNTING のみ閲覧可能。読み取り専用で、本番反映は別途デプロイ指示時に行う。

## 集計

- 単一の正確な口座ID、同一会社・事業者の明細だけを使用。銀行・カード・親子口座は合算しない。APIに通貨情報がないため通貨記号・換算は付けない。
- 通常処理の正の出金・カード利用額。振替・対象外・元明細なし・未来日は除外。入金・返金は差し引かない。振替・対象外の金額は別記する。税務上の経費や利益ではない。
- 当月途中は各月1日から同じ日までを比較。存在しない日は月末で切り詰める。終了した対象月は月合計。過去6か月と対象月を表示。
- 取得済み範囲が連続して期間を覆う場合だけ取得済み表示。未取得の空月は不明でありゼロではない。明細がある未確認月同士の比較は「参考」。前月ゼロの増減率は計算しない。
- 科目別内訳は現在の分類で集計。増減額の合計は全体の増減に一致する。未分類・分類未確認も表示。
- 科目・未分類のリンクは `analysisThrough` により集計と同じ日付上限・正確な口座・事業者・通常出金に限定。ページ移動・並べ替え・摘要検索・科目変更では維持し、月・口座・入出金・分類状態を変えるか明示解除すると通常の明細検索に戻る。
- 個別根拠のリンクは `transaction` により1明細だけ表示。会社境界は維持する。

## 注意候補

同じ摘要とはNFKC正規化・前後空白除去・連続空白集約・小文字化後の完全一致。番号は消さない。空欄・短い摘要・汎用的な銀行語句は判定しない。

1. 重複: 同一口座・同日・同額・同摘要で元明細IDが異なるもの。購入が複数ある場合もあり、二重払いを断定しない。表示金額はグループ合計であり過払い額ではない。
2. 大口: 過去6か月に同摘要が5件以上かつ3か月以上。中央値の2倍以上かつ「中央値＋中央絶対偏差の3倍」より大きい対象月の明細。直近5件と比較基準を表示する。
3. 定期増額: 直前3か月に毎月1件、金額が中央値の±10%以内。対象月に1件だけあり、中央値より20%以上多い場合。契約単価の値上げとは断定せず、利用量の違いも確認を促す。

大口と定期増額・重複の重なりは二重に掲載しない。候補は金額順の上位50件、重複の元明細は先頭8件まで。種類の絞り込みは表示中50件が対象。
閾値は業務上の注意候補を作るヒューリスティックであり、確率・不正検知保証・会計判断ではない。
履歴不足、取得範囲、同期が7日以上古い場合、手動口座・連携終了を明示する。
科目の確認済みは注意候補の確認ではない。正当な支払いを候補から消す永続的な承認機能は未実装。
送金、削除、元明細変更、請求書の入金・支払い変更、外部AIへの送信は一切行わない。
