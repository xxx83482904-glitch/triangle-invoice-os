# 口座の予測

`/banking/forecast?company=JAPAN`。「口座・カード明細」の「予測」から開く。管理者・経理担当のみ閲覧・条件変更できる。本機能は参考予測であり、会計仕訳・確定予定・資金繰りの保証ではない。

## 対象と計算

- 対象は選択した一つの口座、または一つのカード。親口座のサブ口座を合算しない。通貨情報を取得していないため換算・通貨記号の付加もしない。
- 前月までの6か月の月次入金・出金平均を基準に、今月を含む3か月または6か月を予測。前月を含む3か月以上のデータがなければ予測値を表示しない。季節性・傾向の外挿は行わない。
- 取引のある未検証月は「取得範囲未確認」として参考値に使う。明細も取得完了記録もない月は不明であり、ゼロにはしない。API取得完了範囲が月全体を覆っている場合に限り、明細なしをゼロとして使う。
- 同期で全ページを検証・保存できた期間と当時の口座IDを `BankSyncState.coverage` に記録する。過去の同期成功日時だけから取得範囲は推測しない。APIの取得完了は金融機関が未提供の履歴まで揃っている意味ではない。
- 会計上の「対象外」「振替・カード精算」も、選択した口座の現金移動として含む。他口座・カードの利用明細を合算しないので二重計上を避ける。元明細なし・将来日付は除外する。
- 今月の残期間予測は `max(調整後月平均 - 今月実績, 0)`。今月全体の見込みは実績に残期間予測を足す。過去実績自体は変更しない。
- 入金・出金の増減率を個別に変更できる（-100%〜+200%）。慎重ケースは調整後の月額入金を20%減・出金を20%増とし、実績を下回らない。これは想定シナリオであり統計的な信頼区間ではない。

## 残高と設定

- APIから預金残高や口座種別を取得していない。口座種別を「銀行口座」にし、今月1日の残高を入力した場合だけ月末残高を計算する。カードは利用・返金の予測であり銀行引落予定ではない。
- `月末残高 = 今月初残高 + 今月からその月までの累計入金 - 累計出金`。
- 月替わりでは古い月初残高を再利用しない。今月の月初残高を入れ直すまで残高は未設定。月初残高は現在残高ではない。
- 警戒ラインを下回る月末を表示する。日中・月中の残高や実際の支払可否は予測していない。
- 口座種別・月初残高・警戒ライン・増減率を口座ごとに「条件を保存」で保存。権限と更新日時をサーバーで再検証する。保存競合では上書きしない。Undoは予測条件のみを戻し、その後の同期で変わった口座名などは維持する。
- 未保存のリンク・口座切替は保存/破棄/キャンセルを確認。リロード・タブ終了はブラウザーの確認を使う。ブラウザーの戻る操作は未保存ガードの対象外。

## 根拠

- 定期入出金候補: 正規化した摘要と入出金方向が同じで、直近3か月に各月1件ずつあり、最高額と最低額の差が中央値の25%以内。次回金額は中央値、日付は日の中央値（3件とも月末なら月末）。確定予定ではなく、月次平均にすでに含まれる内訳候補なので別加算しない。
- 過去検証: 最低3か月の過去平均で次の月次収支を予測し、観測値との平均絶対誤差を計算。検証回数も表示する。将来の誤差上限・予測確率ではない。
- 未同期/7日以上前の同期、今月の取得範囲未確認、手動管理/連携終了を表示。未決済請求書は入出金との照合ができていないため合算しない。
- この機能は既存データをローカル計算する。外部AIへの送信、新たなAPIキー、Money Forward書き戻し、振込、請求書の自動消込はない。

## 検証

`npm run test:banking` に計算・取得範囲・口座分離・月替わり・定期候補・過去検証・保存権限・競合・Undoのテストを含む。

`node --conditions=react-server --import tsx tests/prepare-forecast-preview.ts` でOSの一時フォルダーに6か月分の架空口座・カード明細を作る。出力パスを `DATA_DIR` に指定し、`DATABASE_URL` とMoney Forwardの環境変数を空にしてローカル起動する。ログインは `admin@example.invalid`、パスワード `local-banking-test-only`。本番へコピーしない。

## 参考資料

- [日本政策金融公庫の資金繰り表記入例](https://www.jfc.go.jp/n/service/pdf/sikinguri_rei.pdf): 前月繰越と入出金による翌月繰越という基本構造。本アプリ独自の平均予測を公庫が推奨・保証するものではない。
- [Forecasting: Principles and Practice](https://otexts.com/fpp3/ses.html): 平均による予測と平滑化の比較。本機能は単純平均の参考ケースであり、同書の高度なモデルや予測区間は実装していない。
