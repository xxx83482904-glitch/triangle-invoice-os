# 日本の請求書担当

`BILLING_EDITOR` は日本の発行請求書専用ロール。一般登録画面からは選択できない。

## 操作範囲

- メニューは発行請求書と取引先。会社切替は日本のみ。中国のクエリ指定でも日本の画面を表示する。
- 日本案件の発行請求書を閲覧・原本確認・OCR取込・手入力作成・編集・CSV出力できる。
- 日本の案件を請求書の紐づけ先として選べる。担当者への個別案件割当は不要。
- OCRで必要な場合に限り日本の新規案件を作成できる。契約金額や案件全体の編集権限はない。
- 日本の請求先クライアントと、発行請求書状態・税率の選択肢を管理できる。支払先や案件進捗の設定は表示しない。
- ダッシュボード、全書類、案件詳細、収支、入金支払い、集計、受領請求書、郵便物、ユーザー管理は対象外。
- 中国のファイル・書類詳細・CSV・取込・取引先更新はサーバーで拒否する。画面の非表示だけに依存しない。

## アカウント作成

ログイン済み管理者のみ `POST /api/admin/invoice-staff` にJSONの `name`・`email`・`password` を指定できる。
作成ロールと会社範囲はサーバー側で固定する。一般登録から権限を選ばせない。
メール重複時は409を返し、既存ユーザーのパスワード・権限・削除状態を変更しない。
パスワードはbcryptでハッシュ化し、ソース・応答・監査ログの作成結果に平文を記録しない。
初期パスワードを毎回復元する処理には追加しない。

## 検証

- `npm run test:documents`、`npm run lint`、`npm run build`。
- `tests/check-billing-access.ts` はローカル一時データ専用。`TEST_BASE_URL` と `TEST_DATA_PATH` を指定する。
- 管理者限定作成、重複時の非上書き、会社分離、直接URL/API/原本/CSVの拒否、請求書OCRを検証する。
- 本番ではユーザーから依頼されたアカウントだけを作成する。検証用の顧客や請求書を追加しない。
