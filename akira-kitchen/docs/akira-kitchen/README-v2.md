# あきらくんと おりょうり v2

3〜6歳向けの、端末内で遊べる料理アプリです。1448×1086の4:3ステージをiPad横向きに合わせて拡縮します。Next.js / React / TypeScriptの既存構成を継続し、公開用には静的ファイルを書き出します。

## 起動

Node.js 22.18以上（開発・テスト環境は24.18）を使用します。元リポジトリから次を実行します。

```powershell
node scripts/prepare-akira-deployment.mjs
cd outputs/akira-kitchen-site
npm install
npm run dev
```

PCは `http://localhost:3060/akira-kitchen/`、同じWi-FiのiPadは `http://PCのIPv4アドレス:3060/akira-kitchen/` をSafariで開きます。PCのアドレスは `ipconfig` で確認できます。Windowsのファイアウォール許可が表示されたら、利用するプライベートネットワークの範囲を確認してください。Safariは横向きで使用します。

元リポジトリで直接起動する場合は `npm run dev -- --hostname 0.0.0.0 --port 3060` です。既存の請求管理アプリも含むため、料理アプリだけを確認する場合は上の独立した配置先を使います。

## テストと本番ビルド

元リポジトリで実行：

```powershell
npm ci --prefix tests/akira-kitchen
npm --prefix tests/akira-kitchen test
npx tsc --noEmit
npx eslint src/app/akira-kitchen
node scripts/prepare-akira-deployment.mjs
cd outputs/akira-kitchen-site
npm run build
```

`out/` が配布可能な静的サイトです。`npm run build` が全JS/CSS/イラストとアプリ本体のキャッシュ一覧を生成します。Nextのビルドだけを直接実行すると本番用Service Workerが生成されないため、上記コマンドを使用してください。アプリ自体はサーバー機能・外部API・ログイン・広告・追跡を使用しません。

独立した配置先だけでテストする場合は、そこで `npm ci --prefix tests/akira-kitchen` を実行後、`npm test` を実行します。

## iPadでのPWA確認

1. HTTPSの公開URLをSafariでオンライン起動し、調理画面を開きます。
2. 設定の「おうちの かたへ」で「オフラインで あそべます」を確認します。
3. Safariの共有メニューから「ホーム画面に追加」します。
4. ホーム画面から起動し、機内モードにして閉じる→再起動→調理→アルバム表示を確認します。

LANのHTTPではSafariがService Workerを許可しないため、オフライン検証にはHTTPSの公開版を使用します。既存Sitesのアクセス範囲は所有者のみのままです。ホスティング側のアクセス確認が必要な場合があります。

## 保存とアセット

- IndexedDB `akira-kitchen-album` / `works`：完成画像のSVG Blob、食材、味、位置、クリームの筆跡、日時。生成イラストをSVG内に一度ずつ埋め込み、保存画像だけで再表示できます。サーバーへ送信しません。
- localStorage `akira-kitchen:session:v2`：進行、表示画面、途中の作品、音設定。再起動時に復元します。
- 旧版 `akira-kitchen:v1` のアルバムは初回に移行します。元データは削除しません。
- 保存済み作品を編集した場合は新しいIDに分け、元の作品を保持します。
- ブラウザのサイトデータを消すと作品も消えます。端末間同期はありません。
- `prototype-shapes.ts`：提供プロトタイプのSVGを、調理中の変形・道具・星とハートなどに再利用。
- `illustration-*.png`：提供画面01・02を参照して、内蔵画像生成で制作した8素材。あきらくん、キッチン背景、お弁当箱、6種のおかず、6種のトッピング、3種類のケーキ。キャラクターの髪・細めの目・歯が見える笑顔・衣装を参照UIに合わせています。
- 素材・生成プロンプトの一覧は [illustrations.md](illustrations.md)。食材は独立したパーツで、画面全体のPNGに透明ボタンを重ねる方式ではありません。

## コードの場所

`src/app/akira-kitchen/`：画面、調理・配置部品、データモデル、IndexedDB、Web Audio、CSS。

`public/akira-kitchen/`：生成イラスト、PWAアイコン、マニフェスト。

`tests/akira-kitchen/`：モデル・UI操作・IndexedDB・音・Service Workerの実行可能なテスト。

`scripts/prepare-akira-deployment.mjs`：料理アプリだけを独立した既存Site配置先へ同期。ルートの請求管理アプリのホスティング設定は使用しません。
