# あきらくんと おりょうり 3.0 — 実装・検証報告

2026-11-01。既存Next.js静的アプリ、公開パス、1448×1086ステージ、レシピ型、session:v2、IndexedDBアルバムを引き継いで改修しました。作業の優先順位とファイル対応は [実装計画](preschool-ux-plan.md) に記録しています。

## 完成した機能

- 全17画面に、事前生成の日本語音声・料理の絵・手のヒントを追加。右上から再生でき、設定でナレーションだけを切り替えられます。
- 指で握る・混ぜる・巻く・入れる・塗る操作、色・数・形のおだい、音とリアクションを実装。厳密なジェスチャーやおだいの未達成で止まらないようにしています。
- お弁当箱1010px、飾るケーキ約940pxの作業面。右棚は回答に従って3個ずつのページ式にしました。タップ配置、移動、90度回転、棚へ戻す、1手取り消し、配置数バッジがあります。
- 空のお弁当・ケーキで完成へ進む操作を防止。ロックされたボタンに触れると音声と手で誘導します。
- 料理を食べても、保存する元の作品は維持。選択した味・形・食材・配置・回転・クリームを埋め込み画像として保存します。
- 設定・アルバム削除に3秒長押しの保護者ゲート、復帰時に一度の「つづきから／さいしょから」、縦持ちと小画面の回転案内を追加しました。
- 人物4ポーズをホームのデフォルメ版からImageGenで生成し統一。以前の写真に近い絵柄は今回指定された統一方針に従って置き換えました。元写真は配布しません。
- WebP・WOFF2・ホーム中心の事前キャッシュ・画面の先読み・残りの素材のバックグラウンド保存を実装しました。

## 容量と表示速度

| 項目 | 実測 | 目標 |
| --- | ---: | ---: |
| WebPイラスト51ファイル | 1,377,480 bytes | 合計5MB以下 |
| アイコンを含む配布画像合計 | 1,408,820 bytes | 合計5MB以下 |
| 最も大きい画像 | 約128KB | 各150KB以下 |
| サブセットWOFF2 | 31,380 bytes | 300KB以下 |
| 起動時キャッシュ | 約1.61MB / 45リソース | 8MB以下 |
| ナレーション102本 | 1,025,016 bytes / 最長1.765秒 | 各2秒以内 |

ローカル静的配布物をgzipで配信し、Chromeの通信を制限してコールドキャッシュで各3回測定しました。1024×768、DPR2、遅延150ms、CPU制限なしです。ホームの人物・お弁当・ケーキの3画像が表示可能になった時点を計測しています。

| 通信速度 | ホームの3画像 | Reactの操作準備を確認した時点 |
| --- | --- | --- |
| 4Mbps | 630〜636ms | 1,481〜1,499ms |
| 1.6Mbps | 1,137〜1,155ms | 2,529〜2,744ms |

ホーム画像の1.5秒目標をこの測定条件で達成しました。画像表示と操作準備の時間は別です。公開回線・実機iPadで同じ時間を保証するものではありません。測定原本は [performance.json](akira-kitchen/qa/browser-v3/performance.json) にあります。

## 未実装・追加確認

主要な料理、配置、味見、保存、設定、PWAの流れに未実装の工程はありません。次の確認・改善は残っています。

1. 実機iPad Safariで、音量・話速、ドラッグの指への追従、ホーム画面追加後の機内モードを確認する。今回のWebKitはWindows上で動作し、実機Safariではありません。
2. 3〜6歳の子どもが説明なしに始められるか、手のヒントに気づくかを観察し、声の速さと間隔を調整する。
3. 低速回線で画像の後にReactの操作準備を待つ時間を短縮する。現時点で1.6Mbpsでは約2.5〜2.7秒。
4. 原本の手描き文字や装飾、料理中の動的SVGには表現上の差がある。世界観と色は維持し、位置や大きさは今回の幼児向け要件に合わせて変更した。

起動・再生成・公開手順は [README](../README.md) を参照してください。初回のオンライン準備が完了するまでは、まだ開いていない画面の完全なオフライン動作を前提にしないでください。
